第 37 章 樣本量計算 Sample Size Calculation

37.1 為什麼樣本量本身會改變證據的重量

前面幾個 session 一直在處理偏倚：隨機化 (randomisation)、對照組 (control group)、盲法 (blinding)、追蹤與報告。如果這些做不好，試驗會偏；但即使方法學上都安排得很仔細，還有一個同樣硬的問題：我們到底需要多少人，才有合理機會看見一個臨床上真正重要的治療差異？樣本量 (sample size) 不是事後裝飾，它決定了試驗能不能給出精確、可信、可用於決策的結果。

計算樣本量時，統計學上關心的是：如果治療效果真的存在，我們希望有多大機率把它檢出來；如果沒有治療效果，我們又願意承擔多大機率誤判成有效。實務上還會受到經費、時間、可招募病人數、倫理與資料監測的限制。這些限制不能用公式消失，但公式能讓我們看清楚妥協的代價。也就是說，樣本量計算不是為了製造一個看起來精確的整數，而是把「臨床上想回答什麼問題」翻譯成「需要多少資訊量」。

下面的例子很能說明這件事。兩個安慰劑對照試驗都在看 streptokinase 對心肌梗死後死亡率的影響，估計出的 risk ratio 幾乎一樣，但證據強度完全不同。

表 37.1: Streptokinase trials after myocardial infarction
Trial Measure Streptokinase Placebo P-value
1st Australian Deaths 26 / 264 (9.8%) 32 / 253 (12.6%) 0.32
1st Australian Risk ratio (95% CI) 0.78 (0.48 to 1.27)
ISIS-2 Deaths 791 / 8592 (9.2%) 1029 / 8595 (12.0%) <0.001
ISIS-2 Risk ratio (95% CI) 0.77 (0.70 to 0.84)

不難注意到，第一個 Australian trial 的相對風險估計是 0.78，ISIS-2 (ISIS-2 (Second International Study of Infarct Survival) Collaborative Group 1988) 是 0.77，方向和大小幾乎一致；可是前者的信賴區間從 0.48 到 1.27，包含了相當大的獲益、也包含沒有明確效果，p 值是 0.32。ISIS-2 因為事件數和總樣本量都大，信賴區間收得很窄，p 值也非常小。這不是第一個試驗「做錯了」，而是它在這個臨床問題上資訊量不足。也就是說，小試驗即使估計值看起來很漂亮，也可能只是在用很寬的區間說一句不夠清楚的話。

37.2 決定樣本量的五個問題

在真正套公式前，我們需要先把試驗問題釘牢。第一，主要結局 (primary outcome) 是什麼？樣本量必須服務於主要目的，不能拿一個容易量的次要結局來替代核心問題。第二，資料將如何分析？二元結局可能是比例或風險差，連續結局可能是兩組均值差，生存結局則可能需要事件數。第三，對照組預期結果是多少？這通常來自既有試驗、觀察性研究、登錄資料或 pilot study。第四，最小臨床重要差異 (smallest clinically important difference) 是多少？這通常是最難、也最容易引發爭論的一步。第五，如果這個差異真的存在，我們希望有多大把握檢出它，也就是 power 要設多少。

這五個問題裡，技術上最標準的是顯著水準和 power，例如常用 5% two-sided significance level、80% 或 90% power；真正敏感的是對照組風險與最小重要差異。如果我們把治療效果假設得過於樂觀，樣本量會顯得很好看，但試驗很可能變成 underpowered trial。相反，如果要求檢出非常小的差異，樣本量會迅速變得巨大，甚至超過可招募病人的上限。於是，樣本量計算本質上是一個臨床判斷與統計判斷的交界點，不是統計師在最後按一下計算機就能替大家決定的事。

用 UK PACE trial (Toff et al. 2005) 作例子，研究者關心 dual chamber pacemaker 是否能比 single chamber pacemaker 降低四年死亡率。對照組死亡率預期是 24%，希望能檢出降到 18% 的差異，也就是 6 個百分點的 absolute risk reduction，或四分之一的 relative reduction；顯著水準設為 5%，power 設為 90%。這些選擇合在一起，最後需要大約 2000 名病人。也就是說，「24% 到 18%」這句臨床假設，比公式本身更先決定了試驗的大小。

37.3 第一類錯誤、第二類錯誤與 power

樣本量公式背後其實是在平衡兩種錯誤。令 \(p_1\) 和 \(p_2\) 表示試驗完成後在標準治療與新治療組觀察到的比例，\(p_1 - p_2\) 是觀察到的 treatment effect。令 \(\pi_1\) 和 \(\pi_2\) 表示設計階段假定的真實比例，\(\pi_1 - \pi_2\) 則是我們認為重要、希望能檢出的真實差異。

如果真實世界沒有治療差異，但試驗結果卻達到統計顯著，這是第一類錯誤 (Type I error)，機率記為 \(\alpha\)。如果真實世界存在我們設定的差異 \(\pi_1 - \pi_2\)，但試驗沒有達到統計顯著，這是第二類錯誤 (Type II error)，機率記為 \(\beta\)。Power 則是 \(1-\beta\)，表示當指定的真實差異存在時，試驗能檢出它的機率。

表 37.2: Type I error, Type II error, and power
Observed trial result Truth: no difference Truth: difference exists
No statistically significant difference \(1 - \alpha\) \(\beta\) (Type II error)
Statistically significant difference \(\alpha\) (Type I error) \(1 - \beta\) (Power)

不難注意到，想要同時把 \(\alpha\) 和 \(\beta\) 都壓得很低，代價就是樣本量上升。5% 顯著水準不是說「治療有效的機率是 95%」，而是在沒有真實差異時，我們接受大約 5% 的 false positive 風險。80% power 也不是說「結果有 80% 機率是真的」，而是在指定的真實差異存在時，我們仍然接受 20% 機率沒檢出它。也就是說，power 是設計階段的性質，不是看到結果以後再拿來解釋 p 值的工具。

兩組比較常用的常態近似因子寫作：

\[ f(\alpha,\beta) = \left(z_{1-\alpha/2} + z_{1-\beta}\right)^2 \]

例如 two-sided \(\alpha = 0.05\) 且 80% power 時，\(z_{1-\alpha/2}=1.96\)、\(z_{1-\beta}=0.84\)，所以 \(f(\alpha,\beta)=(1.96+0.84)^2=7.85\)；若 power 改為 90%，\(z_{1-\beta}=1.28\)，所以 \(f(\alpha,\beta)=10.5\)。

表 37.3: Values of f(alpha, beta) for common significance and power choices
alpha 95% power 90% power 80% power 50% power
0.05 13.0 10.5 7.85 3.84
0.01 17.8 14.9 11.70 6.63

37.4 比較兩個比例：公式與敏感度

若主要結局是二元事件，例如死亡、治癒、是否需要 resuscitation，並且兩組 1:1 分配，設計階段預期標準治療組比例為 \(\pi_1\)，新治療組比例為 \(\pi_2\)，則每組所需樣本量約為：

\[ n = f(\alpha,\beta) \frac{\pi_1(1-\pi_1)+\pi_2(1-\pi_2)} {(\pi_1-\pi_2)^2} \]

這裡使用的是比例而不是百分比；如果用百分比書寫，公式中的 \(1\) 要換成 \(100\)，差異也要用百分點。總樣本量在 1:1 分配時約為 \(2n\)。公式裡最值得盯住的是分母 \((\pi_1-\pi_2)^2\)：想檢出的絕對差異減半，樣本量大約變成四倍。這也是為什麼「我想檢出任何一點差異」在臨床上聽起來合理，在設計上卻常常不可行。

sample_size_proportion <- function(p1, p2, alpha = 0.05, power = 0.8) {
  f <- (qnorm(1 - alpha / 2) + qnorm(power))^2
  n_per_group <- f * (p1 * (1 - p1) + p2 * (1 - p2)) / (p1 - p2)^2
  data.frame(
    p1 = p1,
    p2 = p2,
    alpha = alpha,
    power = power,
    f_alpha_beta = f,
    n_per_group = n_per_group,
    total_n = 2 * n_per_group
  )
}

pace_base <- sample_size_proportion(0.24, 0.18, power = 0.9)
pace_smaller_effect <- sample_size_proportion(0.24, 0.21, power = 0.9)

rbind(
  `24% to 18%` = pace_base,
  `24% to 21%` = pace_smaller_effect
)
##              p1   p2 alpha power f_alpha_beta n_per_group total_n
## 24% to 18% 0.24 0.18  0.05   0.9        10.51       963.2    1926
## 24% to 21% 0.24 0.21  0.05   0.9        10.51      4066.4    8133

不難注意到，從 24% 降到 18% 是 6 個百分點的差異；若改成只要求檢出 24% 到 21%，差異剩下一半，樣本量會從約 1926 人增加到約 8133 人。這不是公式在「懲罰」保守設計，而是小差異本來就很難從抽樣變異裡分辨出來。也就是說，最小重要差異一旦設定得太小，試驗可能會在倫理與資源上都變得不可承受。

37.5 比較兩個均值：標準差與差異大小

若主要結局是連續變數，例如 12 個月 glomerular filtration rate (GFR)、收縮壓、疼痛分數，兩組均值比較的樣本量還需要指定結局的標準差。令 \(\mu_1\) 和 \(\mu_2\) 是兩組預期均值，\(\delta = \mu_1 - \mu_2\) 是希望檢出的均值差，\(\sigma\) 是兩組共同標準差，則每組所需樣本量約為：

\[ n = f(\alpha,\beta) \frac{2\sigma^2}{\delta^2} \]

這個公式和比例公式的邏輯完全一致：想檢出的差異 \(\delta\) 越小，樣本量越大；結果變異 \(\sigma\) 越大，樣本量也越大。連續結局的麻煩在於 \(\sigma\) 往往不如研究者想像得穩定，可能來自小型研究、不同量測方法或不同病人群。於是，對 \(\sigma\) 做敏感度分析不是額外裝飾，而是設計階段的基本動作。

sample_size_mean <- function(delta, sd, alpha = 0.05, power = 0.8) {
  f <- (qnorm(1 - alpha / 2) + qnorm(power))^2
  n_per_group <- f * 2 * sd^2 / delta^2
  data.frame(
    delta = delta,
    sd = sd,
    alpha = alpha,
    power = power,
    f_alpha_beta = f,
    n_per_group = n_per_group,
    total_n = 2 * n_per_group
  )
}

以 REPAIR trial (MacAllister et al. 2015) 為例，研究者希望檢出 RIPC 對 12 個月 GFR 約 4.73 ml/min/1.73m2 的改善，標準差估計為 13.9，5% 顯著水準、80% power。公式給出的每組樣本量約為 136，總共 271 人。若標準差估計上升，樣本量會跟著上升；若標準差下降，樣本量才會下降。也就是說，連續結局的樣本量不是只由「想看到多大差異」決定，也由資料本身有多吵決定。

37.6 樣本量調整：失訪、換治療、不等比例

前面的公式假設每個人都有主要結局資料，也都接受自己被分配的治療。真實試驗很少這麼整齊，所以設計時必須把可預期的資訊損失放進去。若預期有比例 \(Q\) 的病人沒有主要結局資料，常用做法是把原本所需樣本量乘以：

\[ \frac{1}{1-Q} \]

若兩組之間有 treatment switching，令 \(Q_1\) 是第一組轉去第二組治療的比例，\(Q_2\) 是第二組轉去第一組治療的比例，則效果會被稀釋，樣本量近似乘以：

\[ \frac{1}{(1-Q_1-Q_2)^2} \]

若是 active treatment 中有比例 \(Q\) 的人停止治療，而這會讓 active group 更像 control group，則常用調整為：

\[ \frac{1}{(1-Q)^2} \]

另外，有些試驗會採用不等比例分配，例如 2:1 隨機到新治療，以累積更多 safety 或 mechanistic 資料。若分配比例為 \(r:1\)，總樣本量需乘以：

\[ \frac{(r+1)^2}{4r} \]

不難注意到，這個倍數在 \(r=1\) 時等於 1，離 1:1 越遠，總樣本量越大。這不是說不等比例一定錯，而是它要用更多總人數換取某一組更多經驗。也就是說，若主要目標是兩組比較，1:1 是總樣本量效率最高的設計；若研究者想改成 2:1，應該清楚說出多出來的病人數換到了什麼。

adjust_for_loss <- function(n_total, q) n_total / (1 - q)
adjust_for_switching <- function(n_total, q1, q2) n_total / (1 - q1 - q2)^2
adjust_for_unequal_allocation <- function(n_total, r) n_total * (r + 1)^2 / (4 * r)

data.frame(
  scenario = c("15% missing outcome", "5% switching each way", "2:1 allocation"),
  adjusted_total = c(
    adjust_for_loss(272, 0.15),
    adjust_for_switching(272, 0.05, 0.05),
    adjust_for_unequal_allocation(272, 2)
  )
)

37.7 太小的試驗與可行性判斷

試驗太小的問題不只是「可能不顯著」。更麻煩的是，估計值會很不精確，真實效果可能被大幅高估或低估；多個小試驗裡，偶然出現顯著且效果很大的研究更容易被投稿、接受與引用，於是整個證據圖像也可能被 publication bias 扭曲。從倫理角度看，讓病人進入一個幾乎沒有能力回答臨床問題的試驗，也很難說是合理使用他們承擔的時間與風險。

因此，樣本量計算後還要回到可行性：病人來源是否足夠？入組標準是否過窄？是否需要 multi-centre collaboration？是否真的需要超過兩個治療組？是否能接受較不嚴格但仍合理的 power 或顯著水準？這些問題不是要把樣本量「壓到能做」，而是要誠實判斷原本想問的問題能不能被可靠回答。也就是說，如果一個試驗沒有現實機會回答臨床上真正重要的問題，最好的設計決策可能不是硬做，而是改問題、改合作規模，或暫時不做。

37.8 CT practical 04：樣本量計算

37.9 背景 Background

這份 practical 對應 Week 4 的樣本量計算。題目沒有病人層級數據，核心工作是把臨床假設轉成公式中的參數，然後檢查不同選擇會如何改變所需樣本量。我們會刻意保留 R 計算過程，因為手算公式很容易讓人把「每組樣本量」和「總樣本量」混在一起，也容易忘記 power、顯著水準、失訪和不等比例分配其實都只是不同形式的資訊量折損。

f_alpha_beta <- function(alpha = 0.05, power = 0.8) {
  (qnorm(1 - alpha / 2) + qnorm(power))^2
}

ss_proportion <- function(p1, p2, alpha = 0.05, power = 0.8) {
  f <- f_alpha_beta(alpha, power)
  n <- f * (p1 * (1 - p1) + p2 * (1 - p2)) / (p1 - p2)^2
  data.frame(
    p1 = p1,
    p2 = p2,
    alpha = alpha,
    power = power,
    f = f,
    n_per_group = n,
    n_per_group_round = round(n),
    total_round = 2 * round(n),
    n_per_group_ceiling = ceiling(n),
    total_ceiling = 2 * ceiling(n)
  )
}

ss_mean <- function(delta, sd, alpha = 0.05, power = 0.8) {
  f <- f_alpha_beta(alpha, power)
  n <- f * 2 * sd^2 / delta^2
  data.frame(
    delta = delta,
    sd = sd,
    alpha = alpha,
    power = power,
    f = f,
    n_per_group = n,
    n_per_group_round = round(n),
    total_round = 2 * round(n),
    n_per_group_ceiling = ceiling(n),
    total_ceiling = 2 * ceiling(n)
  )
}

37.10 問題 1：Pethidine 與 diamorphine 的分娩鎮痛試驗

問題：一項 double-blind randomised controlled trial 計畫比較 pethidine 與 diamorphine 對分娩女性的鎮痛效果。兩個主要關心的結果是：(i) 女性自覺 pain relief poor；(ii) 新生兒需要 resuscitation。觀察性研究提示 pethidine 組約 40% 女性覺得鎮痛效果差，約 6% 新生兒需要 resuscitation。臨床團隊認為任一結果若能達到 25% proportionate reduction，就足以影響實務。

37.10.1 1a：80% power、5% 顯著水準，檢出 poor pain relief 25% 相對下降

Pethidine 組 poor pain relief 風險設為 0.40，diamorphine 若有 25% 相對下降，風險為 \(0.40 \times 0.75 = 0.30\)。這裡的絕對差異是 10 個百分點。

q1a <- ss_proportion(p1 = 0.40, p2 = 0.30, alpha = 0.05, power = 0.8)

0.4 0.3 0.05 0.8 7.849 353.2 353 706 354 708

先用公式手算。查表得 \(z_{0.025} = 1.96\)，\(z_{0.80} = 0.84\)：

\[f(0.05, 0.80) = (1.96 + 0.84)^2 = 2.80^2 = 7.84\]

\[n = 7.84 \times \frac{0.40 \times 0.60 + 0.30 \times 0.70}{(0.40 - 0.30)^2} = 7.84 \times \frac{0.45}{0.01} = 352.8\]

每組取整為 353，總樣本量 \(2 \times 353 = 706\)。R 用精確的 \(z\) 值（\(f \approx\) 7.85）得到每組約 353 人，總樣本量約 706 人，和手算結果一致。若實際寫 protocol，通常會再把小數與奇偶數處理得更保守一些，但 practical 的重點是重現公式邏輯。

37.10.6 1f–1g：給臨床團隊的建議

如果主要結局是 maternal pain relief，那麼單中心或少數中心試驗仍可能有可行性，尤其是在 80% power、5% 顯著水準、25% 相對下降這種設定下。可是如果主要結局是 neonatal resuscitation，所需樣本量接近 7000，這已經不是一般單中心試驗能承擔的規模，除非團隊願意做大型 multi-centre collaboration，而且認為 neonatal outcome 的臨床價值足以支持這個成本。

若團隊說最多只能招募 500 人，我會很直接地說：這個試驗幾乎無法提供 neonatal outcome 的有用資訊，對 maternal outcome 也未必有足夠 power 檢出原本設定的差異。可以重新討論主要結局、可接受的 effect size、是否擴大中心數，或是否先做 pilot/feasibility study；但不應把 500 人寫成足以回答原問題的 definitive trial。也就是說，資源上限可以改變研究問題，不能偷偷改變統計事實。
