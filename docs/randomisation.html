第 35 章 隨機化 Randomisation

35.1 隨機化的背景與倫理 Background and Ethics of Randomisation

隨機化 (randomisation) 是隨機對照試驗 (randomised controlled trial, RCT) 區別於其他研究設計的核心特徵。在設計一項臨牀實驗時，需要考慮兩個主要問題：其一是試驗規模，即需要招募足夠多的患者，這將在後續 Session 中詳細討論；其二是避免偏倚 (avoidance of bias)——患者的選擇、照護與評估不應在治療組之間存在差異，以確保比較結果不受治療本身以外因素的影響。

35.1.1 歷史背景

第一個被廣泛認可的、設計嚴謹的隨機對照試驗，是由 Sir Austin Bradford-Hill 主持的鏈黴素 (streptomycin) 治療肺結核 (tuberculosis) 試驗，由英國醫學研究委員會 (Medical Research Council, MRC) 於 1948 年發表 (Medical Research Council 1948)。在這項試驗中，107 名結核病患者在七所醫院被隨機分配到兩組：鏈黴素加臥床休息組（S 組）和單純臥床休息組（C 組）。分配採用密封信封系統，每位患者的 X 光片由兩名放射科醫生和一名臨牀醫生獨立評估，均對治療方案保持盲法。

六個月後的結果如下：

表 35.1: MRC 鏈黴素試驗結果 (Medical Research Council 1948)
結局指標 鏈黴素組 (n=55) 對照組 (n=52) P 值
X 光片改善 (X-ray improvement) 28 (51%) 4 (8%) p < 0.001
死亡 (Deaths) 4 (7%) 14 (27%) p = 0.007

不難注意到，這個試驗涵蓋了臨牀試驗設計中幾乎所有被認為必要的特徵：隨機化、盲法評估、明確的結局指標以及對照組。值得一提的是，Bradford-Hill 曾坦言，他在撰寫早期方案時刻意避免使用「隨機化」這個詞——擔心這個概念會嚇退臨牀醫生。

35.1.2 倫理考量

實施隨機化並不是一件理所當然的事，其接受程度在許多情況下面臨挑戰。以下三種情形中，隨機試驗的開展往往十分困難，但這並不代表試驗因此就不可行：

  1. 研究者已相信新治療有效
  2. 觀察性研究顯示治療有效
  3. 該治療方法已廣泛用於臨牀實踐

在第一種情形中，研究者的主觀信念與客觀知識之間的差距是關鍵。事實上，有相當多的隨機試驗推翻了此前對治療效益的主觀信念——Session 1 實習中激素替代療法 (hormone replacement therapy, HRT) 的例子就是一個典型。

隨機化看起來似乎是與臨牀醫生「為每位患者提供最佳治療」的職責相矛盾的，因為治療分配是靠隨機，而非醫生的判斷。然而，當我們真正不確定哪種治療更好時，隨機化恰恰是讓患者獲得最佳照護機會的方式。

以鏈黴素試驗為例，Bradford-Hill 認為不進行隨機化才是不符合倫理的——鏈黴素供應有限，療效尚未確定，在這種情況下，公平地分配試驗機會並嚴謹地評估療效，是對患者最負責任的做法 (Doll 1998)。

一個更為極端的例子是高劑量化療加骨髓移植 (high-dose chemotherapy and bone marrow transplantation, HDC/BMT) 治療乳腺癌的案例。在 1980–90 年代，這一療法在觀察性研究中顯示出令人鼓舞的結果，政治壓力和訴訟風險使得隨機試驗極難開展——估計在 1990 年代有超過 41,000 名女性接受了這種高毒性且昂貴的治療。直到 1999 年，最大規模的 RCT 結果出來，才清楚地顯示 HDC/BMT 對生存期毫無改善。NEJM 編輯評論（2000 年）隨後指出，這種療法「應被放棄，轉而採用有充分依據的替代方案」。也就是說，主觀信念 ≠ 客觀知識。

35.2 隨機化的實踐原則與患者入組 Key Principles and Organisation of Patient Entry

儘管許多試驗報告聲稱進行了隨機對照試驗，卻往往對隨機化的具體過程語焉不詳。隨機化如何實施，與做不做一樣重要——即使是執行不當的隨機化，也可能引入偏倚（正如 Chalmers (2001) 所言，MRC 鏈黴素試驗之所以被視為里程碑，正是因為它清楚地描述了防止分配方案被提前知曉的預防措施）。

35.2.1 兩個核心原則

隨機化有兩個不可缺少的核心原則：

  1. 每位患者對各治療選項有已知的（通常是相等的）機率
  2. 患者或研究者都無法提前預測下一位患者將被分配到哪種治療

於是，以下幾種分配方式在技術上不屬於隨機化：

  • 按患者出生日期分配治療
  • 交替分配（奇偶號交替）
  • 按研究者或患者偏好分配

這些方法的問題在於，治療分配可被事先預測，研究者可能因此影響患者的入組決定，導致結果偏倚。著名的 Lanarkshire 牛奶實驗 (Student 1931) 便是一個歷史教訓：10,000 名兒童被分配每日補充牛奶，另 10,000 名不補充，理論上採用抽籤或字母順序，但執行並不嚴格——結果對照組兒童平均更高、更重，很可能是因為教師（下意識地）把較多的營養不良兒童分配到了補充組，使得「牛奶的效果」難以與基線差異區分。

35.2.2 分配隱蔽的重要性

不難注意到，分配隱蔽 (allocation concealment) 與盲法 (blinding) 是兩個不同的概念，卻同樣重要：

  • 分配隱蔽：研究者在患者入組時不知道下一個分配是什麼（入組前隱蔽）
  • 盲法：患者或研究者在入組後不知道已分配的治療是什麼（入組後隱蔽）

在許多試驗中（尤其是外科干預試驗），完全的盲法難以實現，但分配隱蔽仍然是可以做到、也不應忽略的。Schulz 等人 (1995) 的研究顯示，分配隱蔽不充分或不明確的試驗中，治療效果的估計往往被誇大。

35.2.3 患者入組的組織流程

在隨機化實施中，通常需要考慮兩個主要方面：一是患者入組的組織流程，二是提前準備好的隨機化清單。患者入組的建議流程如下圖所示：

患者符合入組條件
        ↓
臨牀醫生願意接受隨機化
        ↓
獲得患者知情同意
        ↓
患者正式登記入組
        ↓
從隨機化清單分配治療
        ↓
填寫入組表格
        ↓
開始治療

這個流程確保了患者在正式入組、取得知情同意之後才進行治療分配。只有在極少數特殊情況（如緊急醫學）下，才可能在知情同意和登記之前進行治療分配。

35.2.4 知情同意的困難

知情同意 (informed consent) 是入組流程中的關鍵環節，但並非總是容易獲得。CRASH 試驗（研究皮質類固醇靜脈輸注對嚴重頭部外傷患者的效果）就是一個典型例子——頭部受傷並伴有意識障礙的患者可能無法提供真正的知情同意，而緊急情況又不允許延遲等待代理人同意。在 CRASH 試驗的許多醫院中，主治醫生承擔了入組這類患者的責任，就像他們在日常臨牀實踐中為患者指定其他治療一樣。

研究者應同時保留未入組患者的記錄（及其原因），例如不符合入組標準或拒絕同意的患者，以便評估試驗樣本的代表性。

35.3 隨機化清單的處理方式 Methods for Handling Randomisation

研究者在患者入組之前，不應知道治療分配的順序，在非盲法試驗中這一點尤為重要。實踐中有幾種常見的處理機制：

35.3.1 密封信封

密封信封 (sealed envelopes) 是最傳統的方法：每個研究編號對應一個預先分配了治療方案的密封信封。當患者入組時，依序打開下一個信封即可獲得分配結果。這種方法的主要問題在於研究者可能因不滿意分配結果而重新密封或更換信封的順序，難以有效防範。

35.3.2 電話隨機化

電話隨機化 (telephone randomisation) 是目前更為常用的方法：研究者聯絡中央登記辦公室（在多中心試驗中通常設有專門的中央辦公室），在提供患者的必要信息並核實入組資格後，通過電話獲得治療分配結果。這種方式可以有效核查入組資格、提供 24 小時服務，並支援多語言試驗。

以 RITA-3 試驗（1,810 名不穩定冠心病患者，介入治療 vs 保守治療，45 個英國中心）為例，患者分配通過諾丁漢的自動化中央電話系統完成。

35.3.3 網絡隨機化

網絡隨機化 (web-based randomisation) 在近年的試驗中已相當普遍，進一步減少了人工干預的可能。以 REPAIR 試驗（406 對腎臟供受體，比較遠端缺血預處理與對照）為例，研究採用 Sealed Envelope 平台的自動化中央系統：非盲法研究者獲得分配結果並施加干預，而盲法護士負責所有其他數據收集和隨訪。

35.3.4 雙盲試驗的特殊安排

雙盲試驗（患者和研究者均不知情）在治療分配的實際操作上更加複雜——治療本身不能被揭示，否則盲法就被破壞了。這通常需要由藥劑師介入：藥劑師根據預先準備的隨機化清單製備盲法藥物包裝，或由其聯絡中央辦公室獲取分配方案。

HSV 療法降低 HIV 感染率試驗（坦桑尼亞 Mwanza，821 名 HIV 陰性、HSV 陽性女性）就是一個典型例子：流動診所進行現場訪問時需要即時提供藥物，因此預先製備的盲法藥物包裝由藥品供應商的藥劑師按照隨機化清單打包後運送到坦桑尼亞，現場維持盲法。

35.4 簡單隨機化 Simple Randomisation

最基本的隨機化方法是簡單隨機化 (simple randomisation)，其原理等同於拋硬幣——每位患者被分配到某一治療的概率相等，相鄰患者的分配之間沒有任何關聯。在實踐中，通常使用計算機生成的隨機數序列，而非真正地拋硬幣。

35.4.1 利用隨機數分配治療

以兩組試驗為例，可以這樣分配：

隨機數字 分配到的治療組
0 – 4 治療 A
5 – 9 治療 B

若為三組試驗，則可以：

隨機數字 分配到的治療組
1 – 3 治療 A
4 – 6 治療 B
7 – 9 治療 C
0 忽略

從隨機數表中任取一個起點，依次讀取數字並按上述規則分配，便可生成隨機化清單。下面用 R 演示如何用隨機數生成一個含 20 名患者的兩組分配序列：

set.seed(42)
n <- 20
rand_nums <- sample(0:9, n, replace = TRUE)
trt_2grp  <- ifelse(rand_nums <= 4, "A", "B")
cat("隨機數序列：\n", rand_nums, "\n")
## 隨機數序列：
##  0 4 0 8 9 3 1 9 0 7 6 3 8 4 3 9 1 2 8 8
cat("兩組分配：\n", trt_2grp, "\n")
## 兩組分配：
##  A A A B B A A B A B B A B A A B A A B B
cat("A 組人數：", sum(trt_2grp == "A"),
    "；B 組人數：", sum(trt_2grp == "B"), "\n")
## A 組人數： 11 ；B 組人數： 9

35.4.2 簡單隨機化的問題：組間不平衡

不難注意到，簡單隨機化在理論上能確保無偏，但在實踐中，尤其是樣本量有限的試驗中，兩組人數可能出現明顯的不平衡。以下是在不同總樣本量下，出現組間不平衡（概率 > 5%，即 20 個試驗中至少 1 個出現這種情況）的程度：

表 35.2: 簡單隨機化可能出現的組間不平衡
總患者數 可能出現的兩組人數差異（概率 > 5%）
20 6:14
100 40:60
200 86:114
1000 469:531

也就是說，即使在 100 名患者的試驗中，也有可能出現 40:60 的不平衡——這不僅降低統計效能，在試驗中途進行期中分析時還可能造成更嚴重的問題。再者，簡單隨機化往往會產生「看起來不像隨機」的序列（如連續六個相同的治療分配），儘管這完全是正常的隨機結果，卻可能引起研究者的疑慮。

正是由於這些局限，簡單隨機化在大多數試驗中較少直接使用，取而代之的是各種形式的限制性隨機化方法。

35.5 隨機置換區組 Random Permuted Blocks

為了確保在試驗招募的整個過程中，兩組患者人數保持相近，通常採用隨機置換區組 (random permuted blocks) 的方法，也稱為限制性隨機化 (restricted randomisation)。

35.5.1 基本原理

其核心思想是：在每一個「區組 (block)」內，各治療組的患者人數相等，而區組內的治療順序則是隨機排列的。例如，若區組大小為 6（block size = 6），則每 6 名患者中恰好有 3 名分配到治療 A、3 名分配到治療 B，而這 6 個位置的排列是隨機的。

以 ACTION 試驗（7,665 名穩定型心絞痛患者，硝苯地平 GITS vs 安慰劑，區組大小為 6）為例，前 18 名患者的分配序列可能如下：

NNPPPN, NNPPNP, NPPNPN

其中 N 代表硝苯地平，P 代表安慰劑。不難注意到，每組 6 個位置中恰好有 3 個 N 和 3 個 P，但順序各異。

35.5.2 用 R 生成隨機置換區組清單

set.seed(2017)
block_size <- 6
n_blocks   <- 5
trt_labels <- c("A", "B")
half       <- block_size / 2

rand_list <- unlist(lapply(seq_len(n_blocks), function(b) {
  block <- c(rep(trt_labels[1], half), rep(trt_labels[2], half))
  sample(block)  # 在區組內隨機排列
}))

cat("隨機置換區組清單（", n_blocks, "個區組，每組大小", block_size, "）：\n")
## 隨機置換區組清單（ 5 個區組，每組大小 6 ）：
cat(rand_list, "\n")
## B B A A A B B A A B A B A B B B A A B B B A A A A B B A B A
# 顯示每個區組的情況
for (b in seq_len(n_blocks)) {
  idx <- ((b - 1) * block_size + 1):(b * block_size)

35.5.3 可預測性問題

區組隨機化的主要隱患在於可預測性 (predictability)——在非盲法試驗中，如果區組大小已知（如 block size = 6），那麼當前 5 名患者已知 3 名為同一治療時，第 6 名患者的分配就是完全可以預測的。區組越小，可預測性越高：若 block size = 2，則每隔一個位置就可以被預測。

解決辦法有以下幾種：

  • 不告知研究者區組的存在和大小（但有經驗的研究者可以在若干患者入組後推算出來）
  • 隨機變換區組大小：例如 RITA-2 試驗同時使用了區組大小 4 和 6，RITA-3 也採用了相同策略

35.6 分層隨機化與過度分層 Stratified Randomisation and Over-stratification

隨機置換區組確保了兩組患者的人數相近，但仍有可能出現兩組患者在重要基線特徵上分佈不均的情況。例如，一組可能平均年齡更大，另一組可能有更多高風險患者——這些因素若與結局強烈相關，就可能影響治療效果的估計。

35.6.1 基本思路

以一項比較兩種抗抑鬱藥（米安色林 mianserin vs 阿米替林 amitriptyline）的雙盲隨機試驗為例，試驗結束後發現：

治療組 內源性抑鬱 (Endogenous) 反應性抑鬱 (Reactive) 合計
米安色林 8 9 17
阿米替林 19 3 22

不難注意到，兩組中內源性抑鬱與反應性抑鬱的比例差異懸殊。若這兩種抑鬱類型對治療的反應不同，則這種不平衡將嚴重干擾治療效果的比較。

分層隨機化 (stratified randomisation) 的解決思路是：對每個亞組（層，stratum）分別製備隨機化清單，每層內使用隨機置換區組。也就是說，對「內源性抑鬱」的患者用一份清單，對「反應性抑鬱」的患者用另一份清單，確保每種類型的患者在兩個治療組之間平衡。

35.6.2 多中心試驗中的分層

在多中心試驗中，通常需要按中心 (centre) 進行分層，因為不同醫院或中心的患者構成和診療習慣往往存在差異。若不按中心分層，可能導致某個中心的患者大多被分到同一治療組。

以 RITA-3 試驗（45 個英國中心）為例，按中心分層的隨機化清單示意如下：

Margate 中心 Livingstone 中心
I I C C I C I I C C I C C I I I I C C C

其中 I = 介入組，C = 保守治療組。每個中心各自有獨立的隨機置換區組清單。

更複雜的是 RITA-2 試驗（1,018 名心絞痛患者，20 個英國心臟病學中心，冠脈成形術 vs 藥物治療），同時按以下三個因素進行分層：

  • 中心（20 層）
  • 病變血管數（單支 vs 多支）
  • 是否有近期不穩定性心絞痛（是 vs 否）

因此總共需要 20 × 2 × 2 = 80 個分層，每層各有一份隨機置換區組清單（區組大小為 4 或 6）。

35.6.3 過度分層 Over-stratification

分層並非越多越好。當分層因素過多時，就會出現過度分層 (over-stratification) 的問題。以晚期乳腺癌試驗為例，若計劃按以下四個因素分層：

  • 行動能力（2 組）
  • 年齡（2 組）
  • 無病生存期（2 組）
  • 主要轉移灶類型（3 組）

那麼需要的層數為 2 × 2 × 2 × 3 = 24 層；若再加上 10 個中心，則需要 240 個分層。在每個分層中，患者人數將非常有限，隨機置換區組可能大量未完成，反而導致嚴重的整體不平衡。

CHAOS 試驗（維生素 E 在冠心病患者中的應用，2,002 名患者）雖然對 7 個變量進行了分層，但結果顯示許多罕見組合仍然出現了嚴重不平衡——例如女性比例：維生素 E 組 18% vs 安慰劑組 13%，糖尿病患者：10% vs 7%。

35.6.4 是否值得進行分層隨機化？

那麼，分層隨機化值不值得做？好處在於能略微提高統計效能，讓各組基線特徵更均衡，也方便日後的分層分析。代價則是組織上更複雜：分層因素必須在入組時便能可靠收集，層數一旦太多便難以管理。若試驗樣本夠大、沒有計劃期中分析，或關鍵預後因素本身不確定，分層的必要性便大打折扣。

一般建議是：僅按少數幾個關鍵預後因素分層，多中心試驗必須按中心分層。若需要對多個因素同時保持平衡，可考慮下一節介紹的最小化法。

35.7 最小化法與其他隨機化方法 Minimisation and Alternative Methods

35.7.1 最小化法 Minimisation

最小化法 (minimisation) 是一種動態隨機化方法，能夠對多個患者因素同時實現良好的組間平衡，特別適用於分層因素較多、採用分層隨機化會導致層數過多的情況。

其核心思想是：對下一位即將入組的患者，計算分配到每個治療組後的整體組間不平衡程度，以概率 \(p > \frac{1}{2}\) 將患者分配到能使整體不平衡最小的治療組。

以晚期乳腺癌試驗為例，設有四個預後因素：行動能力、年齡、無病生存期、主要轉移灶類型，共 24 個層次。假設已有 80 名患者入組，各因素在兩組的分佈如下（\(\downarrow\) 表示下一位患者的特徵）：

表 35.3: 80 名患者入組後各因素的分佈（↓ 為下一位患者的特徵）
因素與水平 治療 A 治療 B
行動能力 (Ambulatory↓) 30 31
行動能力 (Non-ambulatory) 10 9
年齡 (≤50↓) 18 17
年齡 (>50) 22 23
無病生存期 (<2 年↓) 31 32
無病生存期 (≥2 年) 9 8
轉移灶 (Visceral↓) 19 21
轉移灶 (Osseous) 8 7
轉移灶 (Soft tissue) 13 12

對下一位患者（行動能力正常、年齡 ≤50、無病生存期 <2 年、內臟轉移），計算各治療組的邊際合計：

\[\text{治療 A 合計} = 30 + 18 + 9 + 19 = 76\] \[\text{治療 B 合計} = 31 + 17 + 8 + 21 = 77\]

由於治療 A 的邊際合計較小（76 < 77），以概率 \(p > \frac{1}{2}\)（如 \(p = \frac{2}{3}\) 或 \(p = \frac{3}{4}\)）將這位患者分配到治療 A，以縮小組間差距。若兩組合計相等，則用簡單隨機化決定（第一位患者也用簡單隨機化）。

最小化法不需要預先製備清單——分配決策根據已入組患者的即時記錄動態計算，每位新患者入組後都要更新。手工操作相當繁瑣，通常需要計算機輔助；換來的是可以同時控制多個因素的平衡，比起強行列出所有組合的多層分層隨機化，靈活許多。

35.7.2 其他隨機化方法

35.7.2.1 動態「趕追」法 Dynamic Catch-up Method

動態趕追法 (dynamic catch-up method) 的原理是：先採用簡單隨機化，一旦組間不平衡超過預設閾值（如差距 > 4），就讓落後的治療組以更高概率（如 \(\frac{2}{3}\)）獲得下一個分配。這種方法在非盲法試驗中有治療可猜測性的問題，實踐中使用較少。

35.7.2.2 不等比例隨機化 Unequal Randomisation

大多數試驗以 1:1 的比例分配患者，這在統計上是最有效率的設計。但在某些情況下，不等比例隨機化 (unequal randomisation) 也有其合理性：

  • 積累更多新治療的安全性數據（尤其是當標準治療效果已充分了解時）
  • 提高研究者的參與興趣
  • 一種治療費用遠高於另一種時的經濟考量

例如，Chlorproguanil-dapsone (CD) 對比磺胺多辛-乙胺嘧啶 (SP) 治療非洲兒童瘧疾的試驗，以 4:1（CD:SP）的極端比例隨機化，主要目的是評估 CD 的安全性。但需注意，不等比例分配會降低統計效能——要達到與 1:1 分配相同的統計效能，需要更大的總樣本量。

35.7.2.3 隨機化同意設計（Zelen 設計）

隨機化同意設計 (randomised consent design) 由 Zelen (1979) 提出，適用於兩種治療方案差異懸殊（如激進手術 vs 標準治療），難以獲得知情同意的情況。其流程如下：

  1. 先對符合條件的患者進行隨機化
  2. 被分配到第（1）組的患者不徵求同意，直接接受標準治療 A
  3. 被分配到第（2）組的患者徵求同意，詢問其是否願意接受新治療 B；若拒絕，仍接受標準治療 A
隨機化
   ├──（1）不徵求同意 → 接受 A（標準治療）
   └──（2）徵求同意
               ├── 同意 → 接受 B（新治療）
               └── 拒絕 → 接受 A（標準治療）

分析原則：必須按照原始隨機分配組（「求同意組」vs「不求同意組」）進行比較，而不能只比較實際接受了 B 的患者 vs A 組，否則會引入選擇偏倚（拒絕新治療的患者可能在重要特徵上與同意者不同）。

這一設計的依據是：第（1）組患者本來就會接受標準治療，因此不需要徵求同意，從而避免不必要的焦慮。然而，由於倫理爭議，這種設計並不常用。ECMO 試驗（體外膜肺氧合 vs 傳統療法治療危重新生兒）曾使用這種設計，但引發了廣泛的倫理討論。

35.8 小結 Summary

隨機化的方法不止一種，選哪種取決於試驗規模、入組速度和需要控制的因素。本節介紹的幾種方式，整理如下：

  • 簡單隨機化：等同於拋硬幣，實現最簡單，但樣本量有限時組間不平衡的風險較大，且中途期中分析時問題更突出。適用於大型試驗且無計劃期中分析、資源有限的情況。

  • 隨機置換區組：確保在招募過程的各時間點兩組人數保持相近；需謹慎選擇區組大小（不宜過小）；非盲法試驗中應混合使用不同大小的區組。

  • 分層隨機化：在各層內分別使用隨機置換區組，確保重要預後因素在兩組間均衡；需避免過度分層；多中心試驗必須按中心分層。

  • 最小化法：動態方法，可同時對多個因素實現平衡；不需預先製備清單；計算機輔助為佳。

最後，隨機化 (randomisation) 與隨機抽樣 (random sampling) 是兩個常被混淆的概念，有必要在此明確區分。前者是將個體隨機分配到不同治療組，目的是確保治療比較的公平性；後者是從總體中隨機抽取個體作為調查樣本，目的是確保樣本對總體的代表性。

35.14 問題 5：最小化法分配 Minimisation

問題：用最小化法為相同的 15 名患者分配治療（使用非隨機版本，即以概率 1 分配給差距更大的那一組）。

最小化法的邏輯是：每次新患者入組時，計算「若分配到 I 組，則 I 組在各因素上的邊際合計增加多少」，選擇邊際合計更小（即目前相對落後）的一組。當兩組得分相等時，採用簡單隨機化決定。

# 初始化邊際計數表：行=因素水平，列=Intensive/Standard
margins <- data.frame(
  水平      = c("CW","NB","A-C","W/O","M","F"),
  Intensive = rep(0L, 6),
  Standard  = rep(0L, 6),
  stringsAsFactors = FALSE
)
rownames(margins) <- margins$水平

# 第一位患者用簡單隨機化 → 按解答分配為 Intensive
set.seed(2017)
alloc_minim <- character(15)
alloc_minim[1] <- "Intensive"
for (fac in c(patients$團隊[1], patients$族裔[1], patients$性別[1])) {
  margins[fac, "Intensive"] <- margins[fac, "Intensive"] + 1L
}

# 患者 2–15：依最小化法分配
for (i in 2:15) {
  lvs <- c(patients$團隊[i], patients$族裔[i], patients$性別[i])

  score_I <- sum(margins[lvs, "Intensive"])
  score_S <- sum(margins[lvs, "Standard"])

  chosen <- if (score_I < score_S) {
    "Intensive"
  } else if (score_S < score_I) {
    "Standard"
  } else {
    sample(c("Intensive","Standard"), 1)   # 相等時隨機
  }

  alloc_minim[i] <- chosen
  for (fac in lvs) {
    margins[fac, chosen] <- margins[fac, chosen] + 1L
  }
}

35.16 問題 7–10：討論 Discussion

35.16.1 問題 7：兩種方法的優缺點

問題：比較分層隨機化與最小化法的優缺點。

面向 分層隨機化 最小化法
操作難度 相對簡單；可提前製備信封 需要統計師或程式，每次入組都要計算
邊際平衡 層數少時尚可；層數多時很難 即使因素多，邊際平衡通常很好
聯合分層平衡 每層內由區組保證 無保證（可能在特定組合內失衡）
多中心適用性 容易：每中心提前製備清單 需要中央辦公室即時計算
可預測性風險 固定區組大小時有風險 相對難以預測，但仍可被估算

分層隨機化的操作優勢在於可以「預先備好信封」——各中心拿著清單自行操作，不需要打電話回統計中心。最小化法則相反：每次入組都要查當前的計數表才能決定分配，只要各中心分開管理，計數就會對不上，所以幾乎必須走中央聯絡的路線。

35.16.2 問題 8：如果再加入患者年齡這個因素

問題：哪種方法能更好地延伸，納入患者年齡這個額外的分層因素？

若將年齡二分（如 ≤40 vs >40），分層數從 8 增加到 16；若再加上中心，分層數呈指數級增長，很快超過可管理的上限。相比之下，最小化法只需在邊際計數表中增加「年齡 ≤40」和「年齡 >40」兩行，計算量的增加完全可控。因素再多，結構都不會變。

35.16.3 問題 9：實際如何組織隨機化？

問題：在實踐中應如何組織這項試驗的隨機化工作？

這個試驗背景是真實的——南倫敦案量試驗 (UK700 Trial) 同時跑了兩個子試驗，一個用分層隨機化，另一個用最小化法。

  • 分層隨機化試驗：研究者每次有患者需要入組時打電話給統計中心，提供患者資料，立即從預製清單中拿到試驗 ID 和治療分配。
  • 最小化法試驗：研究者每週將待入組患者清單傳真給統計中心，統計師 Ian White 用 MINIM 軟體完成計算後，把結果傳真回來。

由於入組並不緊急，每週一次的批量處理完全夠用。這也說明最小化法在實踐中不需要複雜的實時系統，一個可靠的中央聯絡機制加上專用軟體就足夠了。

35.16.4 問題 10：中途加入兩個新中心

問題：West Battersea 和 South Battersea 兩個新團隊在試驗中途加入，兩種方法各自如何應對？

兩種方法都能在試驗中途納入新中心。分層隨機化只需為新增的分層組合製備新清單，已有分層不受影響——West Battersea 和 South Battersea 各拿一套新清單，入組照常走。最小化法直接在計數表中加入這兩個中心作為新水平，初始計數為 0，下一位來自新中心的患者入組時就會被納入計算。
