第 36 章 試驗結果的報告 Reporting of Trials

36.1 臨床試驗結果的報告 Reporting of Trials

臨床試驗 (clinical trial) 從設計、執行到數據收集，最後都要回到分析與報告結果。經過可能長達數年的規劃與資料蒐集，研究者第一次看見主要結果時，很容易受到數字本身的吸引；但分析和報告工作不應該到試驗結束後才開始考慮。事實上，數據收集表如何設計、實際蒐集哪些資料、哪些表格與圖形會被放進主要報告，都應該在更早階段就規劃好。

臨床試驗在其過程中通常會蒐集大量數據：基線資料 (baseline information)、追蹤訪視 (follow-up visits)、以及隨時間發生的結局事件 (outcome events)。這意味著有許多分析可以進行、許多方式可以呈現結果。Session 8 會進一步討論數據多重性 (multiplicity) 的問題，而本 session 的重點是假設主要分析指標已確定的前提下，聚焦於結果報告本身，探討如何避免對治療效果產生誤導性印象，以及如何批判性地評價已發表的試驗結果。

36.1.1 試驗結果在何處報告？

隨機對照試驗 (RCT) 的一個重要環節是將結果傳播給需要了解的人。試驗結果可在以下場所報告：

  • 醫學期刊：綜合期刊如 Lancet、NEJM、JAMA、BMJ，或疾病專科期刊如 AIDS、European Journal of Cardiology
  • 學術會議：如歐洲心臟學會 (ESC)、美國臨床腫瘤學會 (ASCO) 的報告
  • 監管機構提交：如美國 FDA、歐洲 EMEA（包括英國 MHRA）
  • 新聞發布：針對一般大眾的媒體報導
  • 資助者報告：向經費來源的研究報告
  • 企業內部報告與商業推廣：企業用於行銷的素材

也就是說，同一份試驗結果可能以截然不同的方式呈現給不同的受眾，而呈現方式的差異會直接影響讀者對結果的理解和判斷。

36.2 試驗報告的品質 Quality of Trial Reports

試驗報告應當清楚說明設計和方法，公正地呈現結果。一份完整的試驗報告通常包含以下內容：

  • 序論 (Introduction)：說明試驗要回答什麼問題，以及研究的依據和背景
  • 方法 (Methods)：詳述試驗的進行方式，包括參與者的選擇與隨機化、干預措施以及使用的統計方法
  • 結果 (Results)：以主要指標 (primary endpoint) 為核心呈現試驗主要發現，並與統計方法相對應
  • 結論 (Conclusions)：應反映設計、方法與結果，將試驗置於外部證據的脈絡中，讓讀者能批判性評價結論是否合理

36.2.1 試驗的效度 Validity

在評估和解讀試驗報告時，有幾個核心問題值得關注，尤其與試驗的規模以及內在效度和外在效度有關。

內在效度 (internal validity) 關注的是試驗結果是否可能不受偏倚影響——也就是說，是否代表了所選樣本中各治療組之間的公平比較。需要考慮的問題包括：隨機化是否正確執行？是否採用了適當程度的盲法？追蹤的完整程度如何？各治療組是否被平等對待？是否進行了恰當的分析？結論是否合理？

外在效度 (external validity) 則關注試驗結果是否與實際臨床情境相關——試驗效果是否反映了目標人群中可預期的結果。需要考慮的問題包括：是否納入了相關的患者？是否使用了合適的對照組？干預措施是否可行？隨訪時間是否適當？結局指標是否恰當？是否充分考慮了其他試驗的外部證據？

不難注意到，內在效度和外在效度之間往往存在緊張關係：嚴格控制入組條件有助於提高內在效度，卻可能限制結果的推廣性。

36.2.2 統計分析計畫與報告準則

預防報告偏倚的主要方法是在試驗開始前制定統計分析計畫 (statistical analysis plan, SAP)，其中包括主要指標和次要指標的規範。SAP 應考慮超出主要指標以外需要報告的資訊，以及結果的呈現方式——這可能涉及骨架表 (skeleton tables) 和圖形的預先製作。

為幫助試驗結果的報告，已有多項指南被發布，包括用於改善期刊報告的臨床試驗報告綜合標準 (Consolidated Standards of Reporting Trials, CONSORT) 聲明 (Schulz et al. 2010)，以及用於向監管機構提交報告的國際協調會議 (International Conference on Harmonisation, ICH-E9) 指南。

36.3 CONSORT 聲明 The CONSORT Statement

CONSORT 聲明已被眾多期刊接受，旨在幫助作者透過一份檢核表 (checklist) 和一份流程圖 (flow diagram) 改善報告品質（詳見 http://www.consort-statement.org/）。

36.3.1 CONSORT 檢核表

CONSORT 檢核表由 22 個條目組成，涵蓋標題與摘要（1 項）、序論（1 項）、方法（10 項）、結果（7 項）和討論（3 項）。每個條目指出在試驗報告中應包含的特定資訊。

36.3.2 CONSORT 流程圖：試驗概況

CONSORT 流程圖是每次發表試驗主要結果時的建議附圖，目的是展示患者在整個試驗過程中的流向——而這在許多試驗中往往報告得很差。流程圖涵蓋四個階段：

  1. 入組 (Enrolment)：多少人被評估適格性、多少人未被納入及原因。以 RITA-2 試驗為例，在招募中心中約有 70,000 名患者接受了冠狀動脈造影，其中約 2,750 名符合入組條件，最終 1,018 名被隨機分組。主要的未入組原因是臨床醫生選擇和患者拒絕。

  2. 分配 (Allocation)：每組被隨機分配的患者人數、實際接受計畫干預的人數以及未接受的原因。RITA-2 中，504 名患者被隨機分配到血管成形術 (PTCA)，514 名被分配到藥物治療，其中 33 名 (6.5%) PTCA 組患者並未實際接受手術——原因包括病情改善、病情惡化（改行搭橋手術）以及患者拒絕。

  3. 追蹤 (Follow-up)：多少患者失聯 (lost to follow-up)、多少中止了干預。

  4. 分析 (Analysis)：最終納入分析的患者人數以及排除原因。

也就是說，CONSORT 流程圖的主要用途是讓讀者能一目了然地理解試驗的完整流程——哪些患者在哪個階段、因為什麼原因離開了試驗。這與意向治療分析 (intention-to-treat, ITT) 的原則密切相關：主要比較應按照患者被隨機分配到的治療組進行分析，不論他們是否實際接受了計畫中的干預。

36.4 試驗報告中的統計問題 Statistics in Trial Reports

Sir Robert Armstrong 在 1986 年曾說：「這份文件包含了一個誤導性的印象，而非謊言——它只是對真相有所節制。」Andrew Lang 則更直接：「他使用統計數據的方式，就像醉漢使用路燈——不是為了照明，而是為了支撐。」這兩段話恰好點出了試驗統計報告中的核心問題：同一組數據，可以被呈現出截然不同的面貌。

36.4.1 P 值與信賴區間 P-values and Confidence Intervals

在臨床試驗報告中，長期以來存在過度強調 P 值的問題，尤其是對「\(P < 0.05\)」的執念。這種做法存在幾個根本性的問題：

  1. \(P < 0.05\) 是一個武斷的界線。考慮 \(P = 0.049\) 和 \(P = 0.051\) 的差異——兩者在實質意義上幾乎沒有差別，但若分別報告為 \(P < 0.05\) 和 \(P = \text{NS}\)（不顯著），則會傳達截然不同的訊息。

  2. P 值本身提供的資訊有限。它只能提供反對虛無假設的證據強度，卻無法告訴我們效果出現在哪個治療組、估計效果有多大、或這個估計有多不確定。

  3. 隨著統計檢定次數增加，至少出現一次 \(P < 0.05\) 的概率急劇上升。假設對兩種實際上沒有差異的治療進行 10 次獨立檢定，至少出現一次 \(P < 0.05\) 的概率約為 40%。

\[P(\text{至少一次} P < 0.05 \mid 10 \text{次獨立檢定}) = 1 - (1 - 0.05)^{10} \approx 0.40\]

Anturane 再梗塞試驗就是一個典型的多重比較陷阱 (The Anturane Reinfarction Trial Research Group 1980)。這項試驗將 1,558 名心肌梗塞患者隨機分配到 sulfinpyrazone 或安慰劑組，平均追蹤 16 個月。

36.4.3 應始終報告信賴區間

建議試驗的主要結果始終以治療效果估計值 + 信賴區間 + P 值的形式呈現。單獨的 P 值反映的是統計顯著性，卻無法衡量臨床重要性。以下兩個問題的答案都應該是肯定的：

  • 是否應該始終使用雙側檢定 (two-sided test)？是的。
  • 是否應該報告實際的 P 值（如 \(P = 0.042\)），而非 \(P < 0.05\)？是的。

值得一提的是，美國 FDA 的監管要求是「兩項設計良好的對照試驗證明療效」，簡化來說就是需要兩次獲得 \(P < 0.05\)。若只做一項試驗，理論上需要達到 \(P < 2 \times (0.025)^2 = 0.00125\)。這種對 \(P < 0.05\) 的過度執著，也是 FDA 及製藥公司需要反思的問題。

36.5 相對效益與絕對效益 Relative vs Absolute Benefits

同一組數據可以用相對差異或絕對差異來呈現治療效果，兩者都很重要，但傳達的訊息可能大不相同。來看一個簡單的例子：兩項各含 200 名患者的試驗，死亡率作為結局指標。

表 36.2: 兩項假想試驗的相對與絕對差異
治療 A 治療 B 治療 X 治療 Y
死亡 2 (2%) 4 (4%) 20 (20%) 40 (40%)
存活 98 96 80 60
合計 100 100 100 100

兩項試驗的風險比 (risk ratio) 完全相同，都是 0.5——即風險減半。然而絕對差異 (absolute difference) 截然不同：試驗 1 的絕對減少量為 2%（從 4% 降至 2%），試驗 2 則為 20%（從 40% 降至 20%）。

於是一個問題浮現：以試驗 1 為例，以下哪句話是正確的？

「治療 A 將死亡風險降低了 50%」

「治療 A 將死亡風險降低了 2%」

事實上兩句話都可以成立，因為前者指的是相對減少 (relative reduction)，後者指的是絕對減少 (absolute reduction)。但第一句顯然更具戲劇效果。也就是說，在報告結果時必須明確區分相對和絕對的風險變化，否則容易誤導讀者。

36.5.1 LIFE 試驗的實例

LIFE 試驗 (Dahlöf et al. 2002) 比較了 losartan 和 atenolol 在 9,193 名高血壓患者中的效果，主要終點為 4.8 年間的死亡、心肌梗塞或中風。結果顯示 losartan 的相對風險降低了 13%（\(P = 0.021\)），95% 信賴區間為 2% 至 23%。然而絕對風險降低僅為每 1,000 人年 4.1 個事件——一個相當小的收益，且估計不精確。

# LIFE 試驗的效果估計
events_losartan <- 508
events_atenolol <- 588
n_losartan <- 4605
n_atenolol <- 4588

# 相對風險
rr <- (events_losartan / n_losartan) / (events_atenolol / n_atenolol)
rr_reduction <- (1 - rr) * 100

# 絕對風險差異
ard <- (events_atenolol / n_atenolol) - (events_losartan / n_losartan)

cat("相對風險 (RR)：", round(rr, 3), "\n")
## 相對風險 (RR)： 0.861
cat("相對風險降低 (RRR)：", round(rr_reduction, 1), "%\n")
## 相對風險降低 (RRR)： 13.9 %
cat("絕對風險差異 (ARD)：", round(ard * 100, 2), "%\n")
## 絕對風險差異 (ARD)： 1.78 %

36.6 平衡效益與危害 Balancing Benefit and Harm

絕對風險允許我們計算兩個重要的臨床指標：

  • 需治數 (Number Needed to Treat, NNT)：估計需要多少名患者接受新治療（與標準治療相比）才能多挽救一個事件。定義為 \(\text{NNT} = 100 / \text{絕對百分比降低}\)。

  • 需害數 (Number Needed to Harm, NNH)：估計需要多少名患者接受新治療才會多造成一個不良事件。定義為 \(\text{NNH} = 100 / \text{絕對百分比增加}\)。

36.6.1 TRITON-TIMI 38 試驗

這兩個指標在權衡效益與危害時特別有用。TRITON-TIMI 38 試驗比較了 prasugrel（新治療）與 clopidogrel 在急性冠狀動脈症候群患者中的效果：

# TRITON-TIMI 38 的 NNT 和 NNH 計算
# 大出血（prasugrel 風險增加）
bleed_prasugrel <- 2.4  # %
bleed_clopidogrel <- 1.8  # %
nnh <- 100 / (bleed_prasugrel - bleed_clopidogrel)

# 心肌梗塞（prasugrel 風險降低）
mi_prasugrel <- 7.3  # %
mi_clopidogrel <- 9.5  # %
nnt <- 100 / (mi_clopidogrel - mi_prasugrel)

cat("大出血的 NNH：", round(nnh), "（約每治療", round(nnh), "名患者多 1 例大出血）\n")
## 大出血的 NNH： 167 （約每治療 167 名患者多 1 例大出血）
cat("心肌梗塞的 NNT：", round(nnt), "（約每治療", round(nnt), "名患者少 1 例心肌梗塞）\n")
## 心肌梗塞的 NNT： 45 （約每治療 45 名患者少 1 例心肌梗塞）

也就是說，使用 prasugrel 大約每治療 45 名患者可避免 1 例心肌梗塞，但約每治療 170 名患者會多造成 1 例大出血。這種效益與危害的量化比較，只有通過絕對指標才能清晰呈現——單靠相對指標（HR = 0.76 和 HR = 1.32）很難直觀理解臨床取捨。

對個體患者而言，評估其出血的個人風險尤為重要，這也突顯了個體化治療決策的必要性。

36.7 Kaplan-Meier 存活曲線 Kaplan-Meier Survival Plots

當試驗的主要結局是某種疾病相關事件發生的時間（如存活時間、疾病復發時間、感染時間等）時，Kaplan-Meier 存活曲線 (Kaplan-Meier survival plot) 是最常用的呈現方式。這些圖形展示的是隨機分組後，隨時間推移經歷事件（或保持無事件狀態）的患者累積比例。

然而，同一組數據的 KM 曲線可以有多種展示方式，而不同的呈現方式可能傳達截然不同的視覺印象。RITA-2 試驗的例子將在 Practical 中詳細探討——三種不同風格的 KM 圖展示完全相同的數據，但觀者的感受大相徑庭。

36.7.1 呈現方式的選擇

KM 曲線主要有兩種呈現方向：

  • 向上的累積事件曲線：展示經歷事件的累積百分比，視覺上強調治療組之間的相對差異
  • 向下的無事件生存曲線：展示保持無事件狀態的百分比，若使用完整的 0%–100% 縱軸，則視覺上強調絕對差異很小

如果在向下的曲線中加入縱軸截斷 (break in scale)，雖然在空間利用上更有效率，但讀者若忽略了刻度的不連續，會嚴重高估治療差異的大小。

36.7.2 COREVALVE 試驗的爭議

COREVALVE 試驗 (Adams et al. 2014) 比較了經導管主動脈瓣置換術 (TAVR) 與外科手術在 795 名嚴重主動脈瓣狹窄患者中的效果。在 NEJM 的摘要中聲稱：「在 as-treated 分析中，TAVR 組 1 年死亡率較低（14.2% vs 19.1%），差異 −4.9%，\(P = 0.04\) for superiority」，並得出結論「TAVR 與顯著較高的 1 年存活率相關」。

然而，使用意向治療 (ITT) 分析和雙側 P 值：

\[\text{1 年死亡率差異} = -4.8\%,\quad 95\% \text{ CI: } [-10.4\%, +0.4\%],\quad P = 0.08\]

信賴區間跨越零，按照傳統統計顯著性標準並未達到。這個例子展示了分析方法的選擇如何影響結論——as-treated 分析排除了未按方案接受治療的患者，可能引入偏倚。

36.8 統計結果的語言表述 Translating Statistical Findings

Pocock and Ware (2009) 在 Lancet 發表了一篇極為實用的評論，提供了如何將統計發現轉化為簡潔日常語言的指引。在試驗報告中，通常需要一句簡短的語句來捕捉主要指標的核心發現——而這句話的措辭直接影響著讀者的判斷。

根據 P 值的大小和信賴區間的範圍，可以區分以下幾種情境：

表 36.3: 優越性試驗中統計結果的建議措辭（改編自 Pocock and Ware (2009)）
情境 P 值範圍 證據強度 建議措辭
A P < 0.001 強證據 「X 優於 Y (is superior)」

對於非劣效性試驗 (non-inferiority trial)，邏輯稍有不同。關鍵在於 95% 信賴區間是否排除了預先設定的非劣效性界值 \(\delta\)：

不難注意到，\(P < 0.05\) 本身是一個連續尺度上的任意切點——\(P = 0.049\) 和 \(P = 0.051\) 攜帶的資訊本質上相同，但在被誤導性地分別解讀時會產生截然不同的結論。「趨勢 (trend)」一詞有時被用於 P 值略高於 0.05 的情況，但最好避免使用，因為它暗示著在證據薄弱時的特殊辯護——畢竟作者通常不會在結果指向相反方向時提及「趨勢」。

36.8.1 次要分析的額外謹慎

在提及亞組發現 (subgroup findings) 或次要指標 (secondary endpoints) 時，需要更大的謹慎。這類結論通常應排除在主要結論和摘要之外。BEAUTIFUL 試驗發現，ivabradine 與安慰劑在主要複合終點上沒有整體差異，但在心率 \(\geq 70\) bpm 的亞組中，心肌梗塞（一個次要指標）有所減少（\(P = 0.001\)）。文章的結論聲稱 ivabradine「可用於降低心率 \(\geq 70\) bpm 患者的冠心病風險」——這種說法過於武斷。

36.8.2 商業利益與學術獨立性

Stuart Pocock 在課堂上反覆強調的一個主題是商業利益與學術獨立性之間的張力。以抗凝血治療的幾項試驗為例：

  • HORIZONS 和 EUROMAX 試驗（均由產業贊助）比較了 bivalirudin 與 heparin + GPI，結果顯示 bivalirudin 在出血方面有優勢
  • HEAT PPCI 試驗（利物浦的單中心公立資助試驗）進行了直接比較，卻顯示 heparin 更有效且同樣安全（MACE 的 \(P = 0.01\)，支架血栓的 \(P = 0.001\)，大出血無差異 \(P = 0.59\)）

DeMets and Califf (2011) 的評論指出：「商業利益與公共健康之間需要更好的平衡」，並感嘆學術界主導的關鍵藥物試驗正在減少。

36.8.3 安全性報告

CONSORT 擴展聲明 (Ioannidis et al. 2004) 專門針對危害 (harms) 的報告提出了建議：蒐集高品質的危害數據、在試驗報告中納入危害資訊、並適當地量化。START 試驗（budesonide vs 安慰劑治療新發哮喘）的初始手稿完全沒有提及兒童生長減緩的問題，直到發表時才加入「3 年生長減少 1.34 cm」的資訊——這正是為什麼安全性報告需要系統化、而非依賴研究者的主觀判斷。

36.9 發表偏倚 Publication Bias

在試驗層面討論完報告問題後，需要再往後退一步——考慮在系統性回顧 (systematic review) 中識別所有相關試驗時的一個特殊問題：發表偏倚 (publication bias)。

雖然大型多中心試驗通常無論結果如何都會發表，但對於較小的試驗而言，顯示新治療有益效果的研究比顯示無效果的研究更可能被發表。原因包括：

  • 研究者更有動機將「陽性」結果投稿到同行評審期刊
  • 期刊編輯更傾向認為「陽性」結果值得發表並送審
  • 審稿人更傾向認為「陽性」結果適合刊登

這個問題因兩個因素而加劇：許多研究樣本量過小，以及對「顯著性」結果（即 \(P < 0.05\)）的過度強調。

36.9.1 腎臟去神經術的教訓

Symplicity 系列試驗提供了一個戲劇性的例子。Symplicity HTN-1 是一項非對照試驗，86 名患者接受腎臟去神經術後 6 個月收縮壓平均降低 22 mmHg。Symplicity HTN-2 是隨機但非盲法試驗，去神經組降低 32 mmHg 而對照組僅降低 1 mmHg。

然而，Symplicity HTN-3 (Bhatt et al. 2014) 使用了隨機、單盲、假手術對照 (sham procedure) 的設計——結果沒有顯示任何治療效果。也就是說，先前那些令人印象深刻的「陽性」結果，很可能是安慰劑效應 (placebo effect) 和評估偏倚的產物，唯有嚴謹的盲法對照試驗才能揭露真相。

表 36.5: Symplicity 系列試驗：從「有效」到「無效」的啟示
試驗 設計 N 收縮壓變化 結論
Symplicity HTN-1 非對照 86 −22 mmHg 似乎有效
Symplicity HTN-2 隨機、非盲法 49 vs 51 −32 vs −1 mmHg 高度有效
Symplicity HTN-3 隨機、單盲、假手術對照 364 vs 171 無治療效果差異 無效

這個案例提醒我們，非對照或非盲法的試驗結果需要非常謹慎地解讀。前期結果即使看起來有希望，也不能取代設計嚴謹的隨機對照試驗。

36.10 CT practical 03：試驗結果報告練習 Reporting Trials Practical

36.11 背景 Background

在臨床試驗中，主要結局 (primary outcome) 的比較經常以事件發生時間 (time-to-event) 作為指標——例如死亡時間 (time to death) 或出院時間 (time to discharge)。這類結果最常用的展示方式就是 Kaplan-Meier 存活曲線，它描繪的是自隨機分組以來，隨時間推移經歷或未經歷某事件的患者累積比例。

本次 Practical 將透過兩個試驗的實際數據，練習臨床試驗結果的呈現、解讀與批判性評價：

36.12.2 Q1.3 期刊發表時應選哪種圖？

問題：若在醫學期刊中僅能展示一張圖，你會選擇哪一種？

36.12.4 Q1.5–1.6 效果估計與替代展示方式

問題：可以給出什麼效果估計和信賴區間？有什麼替代方式可以展示這些數據？

對於心絞痛分級這類有序分類結局，可以計算各時間點上 Grade 2+ 百分比的治療差異（Medical − PTCA）及其 95% 信賴區間。RITA-2 的發表中就是這樣做的——將差異隨時間繪製成圖，讓讀者能同時看到效果大小、方向和不確定性。

替代呈現方式還包括：各時間點的比例差異 (proportion differences) 表格、序貫比例勝算比 (proportional odds ratio)，或堆疊柱狀圖呈現各心絞痛分級的分布。

36.13.5 Q2.6 數據呈現的問題與替代方式

問題：數據呈現有什麼問題？有什麼替代圖形？

原始論文的 Figure 2 展示的是每天的死亡人數柱狀圖，存在幾個根本性的問題：

  • 沒有標示隨時間仍在追蹤中的患者人數——讀者無法計算隨時間變化的事件率
  • 沒有展示累積事件率——讀者很難判斷整體的治療差異趨勢
  • 每天的波動太大，難以辨識有意義的時間模式

更好的展示方式是使用 Kaplan-Meier 存活曲線：

# 模擬兩項試驗的 KM 曲線（基於論文中各日死亡數的累積）
set.seed(123)

par(mfrow = c(1, 2), mar = c(4, 4, 3, 1))

# 芬蘭研究模擬
time_gh_f <- rexp(n_gh_fin, rate = -log(1 - death_gh_fin/n_gh_fin) / 28)
time_pl_f <- rexp(n_pl_fin, rate = -log(1 - death_pl_fin/n_pl_fin) / 28)
event_gh_f <- ifelse(time_gh_f <= 28, 1, 0)
event_pl_f <- ifelse(time_pl_f <= 28, 1, 0)
time_gh_f <- pmin(time_gh_f, 28)
time_pl_f <- pmin(time_pl_f, 28)

surv_fin <- data.frame(
  time = c(time_gh_f, time_pl_f),
  event = c(event_gh_f, event_pl_f),
  group = factor(c(rep("GH", n_gh_fin), rep("Placebo", n_pl_fin)))
)
km_fin <- survfit(Surv(time, event) ~ group, data = surv_fin)
plot(km_fin, fun = "event", col = c(2, 4), lwd = 2,
     xlab = "Days since randomisation", ylab = "Cumulative proportion",
     main = "Finnish study", las = 1, ylim = c(0, 0.5))
legend("topleft", c("GH", "Placebo"), col = c(2, 4), lwd = 2, bty = "n")

# 多國研究模擬
time_gh_m <- rexp(n_gh_multi, rate = -log(1 - death_gh_multi/n_gh_multi) / 28)
time_pl_m <- rexp(n_pl_multi, rate = -log(1 - death_pl_multi/n_pl_multi) / 28)
event_gh_m <- ifelse(time_gh_m <= 28, 1, 0)
event_pl_m <- ifelse(time_pl_m <= 28, 1, 0)
time_gh_m <- pmin(time_gh_m, 28)
time_pl_m <- pmin(time_pl_m, 28)

surv_multi <- data.frame(
  time = c(time_gh_m, time_pl_m),
  event = c(event_gh_m, event_pl_m),
  group = factor(c(rep("GH", n_gh_multi), rep("Placebo", n_pl_multi)))
)
km_multi <- survfit(Surv(time, event) ~ group, data = surv_multi)
plot(km_multi, fun = "event", col = c(2, 4), lwd = 2,
     xlab = "Days since randomisation", ylab = "Cumulative proportion",
     main = "Multinational study", las = 1, ylim = c(0, 0.5))
legend("topleft", c("GH", "Placebo"), col = c(2, 4), lwd = 2, bty = "n")

Kaplan-Meier 曲線清楚呈現了幾個面向：生長激素組的累積死亡率自試驗早期即持續高於安慰劑組；差異在整個 28 天期間始終存在；以及隨時間變化的風險模式遠比每日死亡人數柱狀圖更容易解讀。正如 Pocock et al. (2002) 所建議的，KM 曲線應成為報告時間-事件結局的標準方式。
